# assets

- `icons/` — favicon, app icon exports, small UI glyphs
- `images/` — `og-cover.png` (1200×630 social card), hero art, photography
- `mockups/` — device screenshots and framed app mockups for the page

Ship compressed: PNG through an optimiser, or WebP with a PNG fallback. Keep any single
image under ~250 KB so the page stays fast on mobile data.

Store badges on the page are currently inline SVG placeholders. Swap them for the
official Apple and Google artwork before launch and keep the required clear space —
both companies publish strict badge guidelines.
